# JSONPlaceholder API Tests

Коллекция запросов и автотестов для тестирования API на базе публичного сервиса JSONPlaceholder.

## Что внутри:
- **GET Post by ID**: Позитивный тест. Проверка статус-кода 200 и наличия поля `userId` в ответе.
- **GET Non-Existent Post**: Негативный тест. Проверка статус-кода 404 при запросе несуществующего поста.

## Инструменты:
- Postman
- JavaScript (pm.test)
